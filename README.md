# ⚡ TalentIQ — AI Resume & ATS Diagnostics

TalentIQ is an AI-powered career intelligence engine designed to move beyond rudimentary keyword matching. Using dense sentence embeddings (`all-MiniLM-L6-v2`), the system evaluates deep semantic alignment between candidate resumes and job descriptions, runs ATS structural linting, maps multi-axis domain proficiencies on radar charts, and generates high-impact bullet point rewrites using Google's X-Y-Z formula.

---

### ✨ Key Features
- **Semantic Vector Alignment:** Cosine similarity via Sentence Transformers to assess contextual experience fit.
- **Multi-Axis Domain Radar:** Visual proficiency balance across Machine Learning, Data/Cloud, Analytics, and Software Engineering.
- **ATS Parseability Diagnostics:** Automated linting for quantifiable impact metrics, action verb strength, and contact structure.
- **Targeted Skill Gap Analysis:** Categorized hard-skill extraction with immediate suggestions for missing competencies.
- **X-Y-Z Impact Polisher:** Automated bullet point templates following Google's accomplishment formula.
